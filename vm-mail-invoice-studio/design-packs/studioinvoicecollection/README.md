# VMStudioDesign - Mail Invoice TP 1 — release 1.0

Four matching email and invoice designs: Monochrome Professional, Blue Professional, Minimal Signature, and Pink & Teal. Select each independently in Studio. Includes local blue-wave and pink/teal corner artwork, compact invoice details, distinct item table treatments and email wrappers.

Install the ZIP matching your core edition (VM4: Joomla 5 / PHP 8.1+; VM5: Joomla 6 / PHP 8.3+). Enable VMStudioDesign - Mail Invoice TP 1 with Public access, select the desired Email and Invoice presets, enable both and save. Existing Studio overrides must be applied. Install Studio core 1.0.1 first; then install this 1.0 pack. This is the initial commercial release.

These designs adapt the reference, not reproduce it exactly: the document title and number stay in VirtueMart's native content below branding. Vendor header/footer settings, translated labels, line items and payment plugin markup affect the result. No signature, invoice data or payment information is invented. Palettes are fixed. Decorative artwork is local for PDFs and served from your site in HTML/email; email clients may block images. Native document content remains readable without artwork. Bottom decoration follows content, rather than using a fixed page footer. Existing archived PDFs are unchanged.

Test newly generated invoices and actual shopper/vendor emails on staging, including long orders, tax breakdowns, terms, custom fields and logos. Joomla update metadata is included. Publish the generated edition-specific XML feed and protected ZIP before distribution. Download keys authorize downloads and updates only; installed designs do not require a key to function.

Previews in dist/design-packs/previews are generated through the actual Studio sample/frame pipeline. Item and address styling applies to native inline styles as well as samples; native summary rows are separated visually without calculating or dropping any amounts. Different real-order fields, store PDF settings, item counts and third-party payment markup naturally affect content and pagination.
